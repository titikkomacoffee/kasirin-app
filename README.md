# POS Kasir Pintar (Supabase & PWA Ready)

Aplikasi Point of Sale (POS) Kasir Pintar berbasis Web yang dikembangkan menggunakan **HTML5, Tailwind CSS, JavaScript Vanilla, dan Supabase Database**.

## Fitur Utama
- **Multi-Device & Multi-Role:** Mendukung hak akses Admin, Manajer, dan Kasir.
- **Sesi Login Tetap (Persisted Session):** Pengguna tidak akan logout saat aplikasi ditutup/di-refresh.
- **Pengaturan Metode Pembayaran Dinamis:** Bebas mengaktifkan/menonaktifkan Tunai, QRIS Pakasir, Transfer Bank, dan Kartu Debit.
- **Absensi Selfie Kamera:** Absen wajib foto kamera langsung sebelum memulai shift.
- **Manajemen Pengeluaran & Laba Rugi Realtime:** Pengeluaran otomatis mengurangi laba kotor harian.
- **Integrasi Dynamic QRIS Pakasir:** Pengaturan API Key Pakasir untuk transaksi QRIS otomatis.
